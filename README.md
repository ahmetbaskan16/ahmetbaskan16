# MoodFlix

Kullanıcının ruh haline göre film veya dizi öneren küçük bir web uygulaması.

## Özellikler
- Mutlu, Üzgün, Stresli, Romantik ve Aksiyon Modu ruh halleri.
- Sabit JSON listeden 3–5 öneri.
- Kart yapısında isim, tür, açıklama ve IMDb puanı.
- “Bunu beğenmedim” ile yeni öneri.
- Karanlık / aydınlık mod.

## Çalıştırma
1. Bu klasörü indirin.
2. `index.html` dosyasını tarayıcıda açın.

## Teknik
- Vanilla JavaScript
- Basit state yönetimi ve temiz bileşen mantığı
